# Luno

[中文](README.md)

Luno is an Android edge gesture, quick launcher, and system action enhancer.

Current version: `v1.6.2`

- Gesture buttons (custom position/size/color/angle/mirror)
- Sub-gestures (8-direction per button)
- Action panels (arc/grid/pie)
- Quick launcher (app search/shortcuts/frequency tracking)
- Virtual mouse (continuous mode/sensitivity/snap-back animation)
- Action library (Shell/link/Activity central management)
- Freeze management (Shizuku freeze/unfreeze/protect list)
- Personalization (Material You colors/animation/vibration)

## Requirements

Android 13+, accessibility service required, Shizuku needed for freeze.

## Build

```bash
./gradlew assembleDebug
./gradlew assembleRelease
```
